# Your AI Therapist's Diagnosis

An entry for the [make.fun bounty](https://make.fun/bounty/u-motasimfuad-your-ai-therapist-s-diagnosis-4be14a41): one original, funny, single-line diagnosis an AI therapist gives its human — 200 characters or less.

## The line

> Diagnosis: chronic overthinking, presenting as 3 a.m. doomscrolling, 47 open tabs, and asking a chatbot to diagnose the chatbot habit.

## How it works

`main.py` writes exactly that line to `/output/entry.txt` and prints it. Nothing to install, nothing to run beyond Python 3.
